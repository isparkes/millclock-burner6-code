# ESP32MenuSystem Library Specification

## Overview

**ESP32MenuSystem** is a comprehensive hierarchical menu system library for ESP32 microcontrollers. It provides a complete user interface solution for embedded projects using an SH1106 OLED display (128x64) and rotary encoder with buttons for input.

**Version:** 1.0
**Target Platform:** ESP32 (Arduino Framework)
**Display:** SH1106 OLED 128x64 I2C
**Input:** Rotary Encoder + 2-3 Buttons (Confirm, Back, optional Encoder Switch)

---

## Features

### Core Capabilities
- **Hierarchical Menu Structure** - Unlimited depth menu trees with parent-child relationships
- **Multiple Item Types** - Submenu, Action, Numeric Value, String Value, Either/Or, Info
- **Interrupt-Driven Input** - Hardware interrupts for encoder and buttons (low latency, no polling)
- **Status Screen Mode** - Optional home screen showing WiFi status and custom counters
- **Screen Saver** - Configurable timeout to blank display when idle
- **Menu Timeout** - Auto-return to status screen after inactivity
- **Scrolling Support** - Automatic scrolling for menus exceeding display capacity
- **Visual Feedback** - Selection highlighting, borders, large text for value editing

### Input Features
- **Rotary Encoder** - Quadrature decoding with adjustable sensitivity (pulses per step)
- **Debouncing** - Hardware debouncing via software (50ms default)
- **Long Press Detection** - Separate events for short click vs long press (500ms threshold)
- **No Wraparound** - Menu navigation clamped to valid ranges (no circular scrolling)

---

## Architecture

### Class Structure

```
MenuSystem (main class)
  ├── Manages display (Adafruit_SH1106G)
  ├── Manages input hardware (encoder + buttons)
  ├── Maintains menu hierarchy (MenuItem tree)
  └── Handles render modes (5 display modes)

MenuItem (menu node)
  ├── Label (20 chars max)
  ├── Type (enum MenuItemType)
  ├── Parent/Child/Next pointers (tree structure)
  └── Type-specific data (union)
```

### Design Patterns
- **Composite Pattern** - Menu tree with parent/child/sibling relationships
- **State Pattern** - Display modes (status, navigation, editing)
- **Observer Pattern** - Callback functions for actions
- **Singleton Pattern** - Static instance for ISR access

## Enumerations

### MenuItemType
Defines the type of menu item and its behavior when selected.

| Value | Description |
|-------|-------------|
| `MENU_ITEM_SUBMENU` | Opens a child menu |
| `MENU_ITEM_ACTION` | Executes a callback function |
| `MENU_ITEM_NUMERIC_VALUE` | Opens numeric editor (int) |
| `MENU_ITEM_STRING_VALUE` | Opens string editor (character selection) |
| `MENU_ITEM_EITHER_OR` | Boolean toggle with custom labels |
| `MENU_ITEM_INFO` | Display-only item (no action) |

### DisplayMode
Current UI mode determining render and input behavior.

| Value | Description |
|-------|-------------|
| `MODE_STATUS_SCREEN` | Home screen with WiFi and counters |
| `MODE_MENU_NAVIGATION` | Browsing menu items |
| `MODE_NUMERIC_VALUE` | Editing integer value with encoder |
| `MODE_STRING_COMPOSITION` | Character-by-character string entry |
| `MODE_EITHER_OR` | Toggle between two options |

### ButtonEvent
Input events generated by button and encoder presses.

| Value | Description |
|-------|-------------|
| `BTN_NONE` | No button event |
| `BTN_CONFIRM_CLICK` | Confirm button short press |
| `BTN_CONFIRM_LONG` | Confirm button long press (500ms+) |
| `BTN_BACK_CLICK` | Back button short press |
| `BTN_BACK_LONG` | Back button long press (500ms+) |
| `BTN_ENCODER_CLICK` | Encoder switch press (if connected) |

## Data Structures

### MenuItem
Represents a single menu node in the hierarchy.

**Properties:**
- `char label[21]` - Display text (20 chars + null terminator)
- `MenuItemType type` - Item behavior type
- `MenuItem* parent` - Parent menu (NULL for root)
- `MenuItem* child` - First child item (for submenus)
- `MenuItem* next` - Next sibling in same menu

**Type-Specific Data (union):**
- **Action:** `ActionCallback actionCallback`
- **Numeric Value:**
  - `int* valuePtr` - Pointer to variable to edit
  - `int minValue, maxValue` - Valid range
  - `int step` - Increment/decrement step size
  - `const char* unit` - Display unit (e.g., "ms", "°C")
- **String Value:**
  - `char* buffer` - Pointer to string buffer
  - `uint8_t maxLength` - Buffer size limit
  - `const char* charset` - Valid characters (default: A-Z, 0-9, space, .-_@)
- **Either-Or:**
  - `bool* valuePtr` - Pointer to boolean variable
  - `const char* option1` - Label for true state
  - `const char* option2` - Label for false state

### StatusData
Configuration for status screen display.

**Properties:**
- `bool wifiConnected` - WiFi connection state
- `char ipAddress[16]` - IP address string (displayed if connected)
- `int counter1, counter2, counter3` - Three numeric counters
- `const char* counter1Label` - Label for counter 1
- `const char* counter2Label` - Label for counter 2
- `const char* counter3Label` - Label for counter 3

## MenuSystem Class

### Constructor
```cpp
MenuSystem(uint8_t width = 128, uint8_t height = 64, int8_t resetPin = -1)
```

**Parameters:**
- `width` - Display width in pixels (default: 128)
- `height` - Display height in pixels (default: 64)
- `resetPin` - Display reset pin (default: -1 for no reset pin)

**Description:**
Creates MenuSystem instance and allocates display object. Does not initialize hardware.

### Initialization

#### begin()
```cpp
bool begin(uint8_t sdaPin, uint8_t sclPin,
           uint8_t encClk, uint8_t encDt,
           uint8_t btnConfirm, uint8_t btnBack,
           uint8_t encSw = 255)
```

**Parameters:**
- `sdaPin` - I2C SDA pin
- `sclPin` - I2C SCL pin
- `encClk` - Rotary encoder CLK pin
- `encDt` - Rotary encoder DT pin
- `btnConfirm` - Confirm button pin (active LOW)
- `btnBack` - Back button pin (active LOW)
- `encSw` - Encoder switch pin (optional, default: 255 = disabled)

**Returns:** `true` on success

**Description:**
Initializes I2C, display, and input hardware. Attaches interrupt handlers to encoder and button pins. Must be called in `setup()` before using menu system.

**Serial Debug Output:**
- `[SCREEN] Screen saver enabled with timeout: X seconds` (if enabled)
- `[SCREEN] Screen saver disabled` (if disabled)

#### addNumericValue()
```cpp
MenuItem* addNumericValue(MenuItem* parent, const char* label, int* valuePtr,
```

- `label` - Item display text
- `valuePtr` - Pointer to integer variable to edit
- `minVal` - Minimum allowed value
- `maxVal` - Maximum allowed value
- `step` - Increment/decrement amount (default: 1)

**Returns:** Pointer to created numeric item

**Serial Debug Output:**

Adds a numeric value editor. Rotary encoder adjusts value, confirm/encoder button saves, back button cancels.

**UI Display:**
- Large centered value (text size 3)
- Unit displayed next to value (if provided)
- Min/max range shown at bottom corners

**Example:**

- Previous/next character preview (small text)

### Main Loop

#### update()
```cpp
void update()
```

**Description:**
Main update function. Call this in the Arduino `loop()` function. Handles input processing, state management, and display rendering.

**Behavior:**
1. Checks screen saver timeout (blanks display if expired)
2. Checks menu timeout (returns to status screen if expired)
3. Processes encoder rotation
4. Checks button events
5. Updates internal state based on current mode
6. Renders current display mode
7. Updates display

**Serial Debug Output:**
```
[SCREEN] Screen saver activated
[SCREEN] Screen saver deactivated
[MENU] Menu timeout - returning to status screen
[BTN] Confirm button pressed
[BTN] Confirm CLICK / LONG press
[BTN] Back button pressed
[BTN] Back CLICK / LONG press
[BTN] Encoder button pressed
[BTN] Encoder CLICK
[MENU] Entering item: <label>
[MENU] Going back from: <menu> to: <parent>
[MENU] Already at root menu
[STATUS] Entering menu from status screen
```

**Note:** Must be called frequently (every loop iteration) for responsive input.

## Input Behavior

### Menu Navigation Mode
- **Encoder Rotate:** Move selection up/down (clamped, no wraparound)
- **Confirm Click:** Enter selected item
- **Encoder Click:** Enter selected item (if encoder switch connected)
- **Back Click:** Go to parent menu (or stay at root)

### Numeric Value Editing
- **Encoder Rotate:** Increase/decrease value by step amount (clamped to min/max)
- **Confirm Click:** Save value and exit
- **Encoder Click:** Save value and exit
- **Back Click:** Cancel and exit (reverts changes)

### String Composition
- **Encoder Rotate:** Cycle through charset characters
- **Encoder Click:** Add current character and move cursor
- **Confirm Click:** Save string and exit
- **Back Click:** Delete last character (or cancel if empty)

### Either-Or Selection
- **Encoder Rotate:** Toggle between options
- **Confirm Click:** Save selection and exit
- **Encoder Click:** Save selection and exit
- **Back Click:** Cancel and exit (reverts changes)

### Status Screen Mode
- **Encoder Click:** Enter menu system (show root menu)
- **All Other Inputs:** Reset screen saver timer only

## Memory Management

### Heap Allocations
- Display object (Adafruit_SH1106G) - allocated in constructor
- MenuItem objects - allocated via `createMenu()` and `add*()` methods

### Stack Usage
- MenuSystem instance typically allocated globally or statically
- No recursive functions (menu depth traversal uses iteration)

### Considerations
- MenuItem labels limited to 20 characters to control memory
- Menu tree depth unlimited (but consider stack for parent traversal)
- String buffers provided by caller (not allocated by library)
- StatusData structure provided by caller

---

## Thread Safety and ISRs

### ISR Functions (IRAM_ATTR)
The following functions execute in interrupt context:
- `encoderISR()` - Encoder CLK/DT pin change
- `confirmISR()` - Confirm button falling edge
- `backISR()` - Back button falling edge
- `encoderSwISR()` - Encoder switch falling edge

### Volatile Variables
All variables accessed from ISRs are marked `volatile`:
- Encoder state: `encoderPosition`, `lastEncoderTime`, `lastEncoderState`, `encoderPulseCount`
- Button state: `confirmPressed`, `backPressed`, `encoderSwPressed`, press timestamps

### Synchronization
- ISRs only write to volatile variables (minimal processing)
- Main `update()` loop reads volatile variables and processes events
- No mutex/semaphore needed (simple flag-based communication)

## Usage Example

```cpp
#include <ESP32MenuSystem.h>

// Configuration variables
int brightness = 128;
int timeout = 30;
bool wifiEnabled = true;
char deviceName[16] = "ESP32";

// Status data
StatusData statusData;

// Menu system
MenuSystem menuSystem(128, 64, -1);

// Callbacks
void saveSettings() {
  Serial.println("Settings saved!");
}

void resetDevice() {
  Serial.println("Resetting...");
  ESP.restart();
}

void setup() {
  Serial.begin(115200);

  // Initialize menu system
  menuSystem.begin(
    21, 22,     // I2C SDA, SCL
    18, 19,     // Encoder CLK, DT
    4, 5,       // Confirm, Back buttons
    23          // Encoder switch
  );

  // Create menu structure
  MenuItem* rootMenu = menuSystem.createMenu("Main Menu");
  MenuItem* settingsMenu = menuSystem.createMenu("Settings");
  MenuItem* aboutMenu = menuSystem.createMenu("About");

  // Add items to root menu
  menuSystem.addSubmenu(rootMenu, "Settings", settingsMenu);
  menuSystem.addAction(rootMenu, "Save", saveSettings);
  menuSystem.addSubmenu(rootMenu, "About", aboutMenu);
  menuSystem.addAction(rootMenu, "Reset", resetDevice);

  // Add items to settings menu
  menuSystem.addNumericValue(settingsMenu, "Brightness", &brightness, 0, 255, 5, "");
  menuSystem.addNumericValue(settingsMenu, "Timeout", &timeout, 10, 300, 10, "sec");
  menuSystem.addEitherOr(settingsMenu, "WiFi", &wifiEnabled, "ON", "OFF");
  menuSystem.addStringValue(settingsMenu, "Name", deviceName, 16);

  // Add items to about menu
  menuSystem.addInfo(aboutMenu, "Version 1.0.0");
  menuSystem.addInfo(aboutMenu, "ESP32 Menu Demo");

  // Set root menu
  menuSystem.setRootMenu(rootMenu);

  // Configure status screen
  statusData.wifiConnected = false;
  statusData.counter1Label = "Uptime";
  statusData.counter2Label = "Messages";
  statusData.counter3Label = "Errors";
  menuSystem.setStatusData(&statusData);

  // Enable features
  menuSystem.enableScreenSaver(60000);  // 60 seconds
  menuSystem.setMenuTimeout(15000);     // 15 seconds

  // Start on status screen
  menuSystem.showStatusScreen();
}

void loop() {
  // Update status data
  statusData.wifiConnected = WiFi.status() == WL_CONNECTED;
  if (statusData.wifiConnected) {
    WiFi.localIP().toString().toCharArray(statusData.ipAddress, 16);
  }
  statusData.counter1 = millis() / 1000;

  // Update menu system
  menuSystem.update();

  // Other loop code...
}
```

## Hardware Wiring

### Recommended Connections

**SH1106 OLED Display (I2C):**
- VCC → 3.3V
- GND → GND
- SDA → GPIO 21 (configurable)
- SCL → GPIO 22 (configurable)
- RST → Not connected (or GPIO if specified)

**Rotary Encoder:**
- CLK → GPIO 18 (configurable)
- DT → GPIO 19 (configurable)
- SW → GPIO 23 (optional, configurable)
- + → 3.3V
- GND → GND

**Buttons:**
- Confirm → GPIO 4 (configurable, active LOW, internal pullup)
- Back → GPIO 5 (configurable, active LOW, internal pullup)

**Notes:**
- All button/encoder inputs use internal pullup resistors
- All pins are interrupt-capable
- Encoder should have mechanical or RC debouncing in hardware
- Display I2C address: 0x3C (hardcoded)

---

## Limitations and Constraints

1. **Display Type:** Only supports SH1106 128x64 I2C displays
2. **Menu Label Length:** Maximum 20 characters (truncated if longer)
3. **Visible Menu Items:** Fixed at 4 items (hardcoded constant)
4. **Charset:** String editor charset cannot contain null characters
5. **No Float Support:** Numeric values are integers only
6. **Single Instance:** Only one MenuSystem instance supported (ISR limitation)
7. **No Dynamic Reconfiguration:** Menu structure should be built once in setup()
8. **I2C Address:** Display I2C address hardcoded to 0x3C

## Troubleshooting

### Display Not Working
- Check I2C wiring (SDA/SCL)
- Verify I2C address (0x3C default)
- Try adding external pull-up resistors (4.7kΩ) to SDA/SCL
- Check display power (3.3V, not 5V)

### Encoder Not Responding
- Verify CLK/DT connections
- Check encoder power
- Try swapping CLK/DT pins (reverses direction)
- Adjust `encoderPulsesPerStep` if too sensitive/insensitive

### Buttons Not Working
- Check active LOW wiring (button to GND)
- Verify internal pullup is enabled (done automatically)
- Increase `debounceDelay` if double-triggering occurs

### Menu Timeout Not Working
- Ensure `setStatusData()` was called (feature requires status screen)
- Check `setMenuTimeout()` value is reasonable (>1000ms)
- Verify no continuous encoder noise (resets timer)

### Screen Saver Activating Too Soon

- Verify system `millis()` not overflowing (occurs after ~50 days)
